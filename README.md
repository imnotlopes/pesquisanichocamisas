# Pesquisa de Nicho — Camisas Sociais de Performance (ATHLOS)

Raio-X completo do nicho de camisas sociais de performance: demanda, concorrentes,
mídia paga, oferta, catálogo, UX, criativos e identidade visual.

## Como abrir

Abra o arquivo [`index.html`](index.html) no navegador (ele redireciona para o relatório completo),
ou vá direto em [`01-pesquisa/Pesquisa - clique aqui.html`](01-pesquisa/Pesquisa%20-%20clique%20aqui.html).

## Estrutura

| Pasta | Conteúdo |
| --- | --- |
| `01-pesquisa/paginas/` | Páginas do relatório: demanda, mercados, anúncios, estratégia, plano de ação, identidade visual, benchmark visual, mockups e fichas de loja dos concorrentes |
| `01-pesquisa/paginas/criativos/` | Criativos reais capturados da biblioteca de anúncios dos concorrentes (vídeos e imagens) |
| `01-pesquisa/capturas-concorrentes/` | Screenshots de home e PDP dos concorrentes (desktop e mobile) |
| `01-pesquisa/capturas-blueprint/` | Screenshots do blueprint proposto para a ATHLOS |
| `01-pesquisa/dados/` | Dados estruturados (JSON) e scripts de captura em Node (`.mjs`) |
| `01-pesquisa/Referencia de imagens - cena e prompt/` | Por produto: referências de imagem, prompts em inglês, manifesto e modelo de página |

## Concorrentes analisados

Kojo Fit, Nimble Made, SAVID, Tailored Athlete e Buffery.
