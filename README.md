# Pesquisa de Nicho — Camisas Sociais de Performance (ATHLOS)

Raio-X completo do nicho de camisas sociais de performance: demanda, concorrentes,
mídia paga, oferta, catálogo, UX, criativos e identidade visual.

**Rodada 1:** 28/08/2026. **Rodada 2 (atualização):** 27/09/2026 — veredito mantido
(VALIDAR COM LIMITE), com ângulo de abertura, oferta e calendário ajustados.
O que mudou está em [`01-pesquisa/paginas/atualizacao.html`](01-pesquisa/paginas/atualizacao.html).

## Como abrir

Abra o arquivo [`index.html`](index.html) no navegador (ele redireciona para o relatório completo),
ou vá direto em [`01-pesquisa/Pesquisa - clique aqui.html`](01-pesquisa/Pesquisa%20-%20clique%20aqui.html).

## Estrutura

| Pasta | Conteúdo |
| --- | --- |
